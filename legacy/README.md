# Legacy archive

Esta carpeta conserva material historico del proyecto que no forma parte del flujo activo de entrega.

- `backend/legacy_components/`: implementaciones y pruebas antiguas del backend.
- `prototypes/teams-tab/`: prototipo inicial independiente basado en Vite.
- `results/backend_analysis/`: resultados y notas de evaluacion generados durante iteraciones previas.
- `scripts/`: utilidades de diagnostico, mantenimiento y configuraciones de umbrales ya sustituidas.
- `patches/`: scripts puntuales usados durante fases previas de refactorizacion.

El codigo activo se encuentra en `backend/`, `frontend/`, `docs/` y los scripts de entrenamiento vigentes en `backend/scripts/training/`.
